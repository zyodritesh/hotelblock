# HotelBlock

Reserve exclusive hotel room blocks for teams, weddings, and gatherings.

## Stack

- React 19 + TypeScript
- Vite

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## What’s included

- Branded landing experience
- Featured properties with selectable inventory
- Room-block reservation form with live estimate
- Hold confirmation with a shareable block code
